# XEROX CATALOGUE — reusable style + test episode

Style config: `config/xerox_catalogue.json` (palette, fonts, texture set, halftone/misregistration, stepped-motion rates,
easing, transition list, film-damage rules). Engine: `xerox_lib.py` (halftone photocopy, paper cards + hard shadows,
ransom-note lettering, marker strokes, price tag/barcode draw-on), `transitions.py` (paper_slap, copier_flash,
torn_reveal, staple_pop, burn/flicker damage). Textures are generated by `textures.py` into `assets/textures/`.

Episode pipeline (run from this folder, `PYTHONHASHSEED=0`):
1. `python timeline.py`   – Kokoro narration (local) + word-level timeline
2. `python audio.py`      – voice + synthesised music/foley -> `audio/mix.wav`
3. `python render.py render/silent.mp4` – frames -> H.264
4. mux: `ffmpeg -i render/silent.mp4 -i audio/mix.wav -map 0:v -map 1:a -c:v libx264 -crf 23 -c:a aac render/fight_club_xerox_test.mp4`

New episode = new `LINES`/scenes in `timeline.py` + `episode.py`; the look comes from the config + lib.
Asset sources/licences: `assets/ASSETS.md`.
